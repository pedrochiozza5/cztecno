## Cómo subirlo a GitHub Pages

1. Crear un repositorio en GitHub.
2. Subir el contenido de la carpeta, no el ZIP.
3. Ir a Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main.
6. Folder: /root.
7. Guardar.
